# Customer Shopping Behavior Analysis

🌐 Portfolio Website: [https://your-portfolio-link.com](https://data-analyst-portfolio-akdj.onrender.com/)

## Project Overview

This project focuses on analyzing customer shopping behavior using transactional retail data. The analysis aims to uncover customer purchasing patterns, product preferences, subscription behavior, and revenue trends to support business decision-making.

The project includes:

* Data Cleaning & Feature Engineering using Python
* Business Query Analysis using SQL & PostgreSQL
* Interactive Dashboard Development in Power BI

---

# Dataset Information

* Total Records: 3,900
* Total Columns: 18

### Key Features

* Customer Demographics
* Product Categories
* Purchase Amount
* Subscription Status
* Review Ratings
* Shipping Preferences
* Discount Usage
* Purchase Frequency

---

# Project Workflow

## 1. Data Cleaning & Preparation

Performed data preprocessing using Python and Pandas:

* Handled missing values
* Renamed columns for consistency
* Created new features:

  * `age_group`
  * `purchase_frequency_days`
* Removed redundant columns
* Checked data consistency

---

# 2. SQL Business Analysis

Performed business-driven analysis using PostgreSQL:

### Key Business Questions

* Revenue generated by gender
* Top-rated products
* Customer segmentation
* Discount impact analysis
* Subscription behavior analysis
* Repeat buyer analysis
* Top-selling products by category
* Revenue contribution by age groups

---

# 3. Dashboard Development

Created an interactive Power BI dashboard to visualize:

* Revenue Analysis
* Customer Segmentation
* Category-wise Sales
* Subscription Insights
* Purchase Trends
* Age Group Analysis

---

# Key Insights

* Male customers generated higher overall revenue.
* Loyal customers represented the largest customer segment.
* Express shipping users showed slightly higher average spending.
* Certain products were highly dependent on discounts.
* Young adults contributed the highest revenue among age groups.

---

# Business Recommendations

* Improve customer loyalty programs
* Promote subscription benefits
* Optimize discount strategies
* Focus marketing on high-performing customer groups
* Highlight top-rated products in campaigns
